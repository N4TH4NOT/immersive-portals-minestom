# Datapack de génération de portails

[English](README.md) · [Français](README.fr.md)

Exemples optionnels pour ce fork. Compiler avec `./gradlew examplePortalDatapack` ; installer le ZIP de `build/examples/` à la création du monde.

Les règles figurent dans [`data/i_am_namespace/immersive_portals/custom_portal_generation/`](data/i_am_namespace/immersive_portals/custom_portal_generation). Le pack enregistre ses dimensions par datapack vanilla, sans DimLib ; format dans [pack.mcmeta](pack.mcmeta). Sauvegarder les mondes existants avant de modifier les définitions de dimensions.
