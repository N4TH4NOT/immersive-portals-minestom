# Portal generation datapack

[English](README.md) · [Français](README.fr.md)

Optional examples for this fork. Build with `./gradlew examplePortalDatapack`; install the ZIP from `build/examples/` when creating a world.

Rules live in [`data/i_am_namespace/immersive_portals/custom_portal_generation/`](data/i_am_namespace/immersive_portals/custom_portal_generation). The pack registers its own dimensions through vanilla datapacks, without DimLib; see [pack.mcmeta](pack.mcmeta) for the format. Existing worlds need a backup before changing dimension definitions.
